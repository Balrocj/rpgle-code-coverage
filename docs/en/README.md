## 📖 About this extension

RPGLE Code Coverage is a Visual Studio Code extension designed specifically for code coverage analysis of RPGLE applications. It integrates with IBM i systems via the Code for IBM i extension and provides professional PDF and HTML reports as well as in-editor highlighting of covered and uncovered lines.
