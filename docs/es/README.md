## 📖 Acerca de Esta Extensión

RPGLE Code Coverage es la primera extensión de Visual Studio Code diseñada específicamente para el análisis de cobertura de código RPGLE. Proporciona integración perfecta con sistemas IBM i a través de la extensión Code for IBM i, ofreciendo reportes profesionales en PDF y HTML con visualización en tiempo real de líneas de código cubiertas y no cubiertas.
