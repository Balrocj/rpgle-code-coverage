## About / Acerca de

**English:** RPGLE Code Coverage is the first Visual Studio Code extension specifically designed for RPGLE code coverage analysis. It provides seamless integration with IBM i systems through the Code for IBM i extension.

**Español:** RPGLE Code Coverage es la primera extensión de Visual Studio Code diseñada específicamente para el análisis de cobertura de código RPGLE. Proporciona integración perfecta con sistemas IBM i a través de la extensión Code for IBM i.

---

## Key Features / Características Principales

✅ **Simple Setup** / **Configuración Simple** - Only 2 required parameters / Solo 2 parámetros requeridos  
✅ **Professional Reports** / **Reportes Profesionales** - PDF and HTML output / Salida en PDF y HTML  
✅ **Real-time Visualization** / **Visualización en Tiempo Real** - See coverage in your editor / Ver cobertura en el editor  
✅ **IBM i Integration** / **Integración con IBM i** - Native Code for IBM i support / Soporte nativo  
✅ **Process Existing Files** / **Procesar Archivos Existentes** - Import .cczip files / Importar archivos .cczip
